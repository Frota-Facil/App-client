Este é o guia completo de componentes, padrões e fundamentos visuais do sistema Frota Fácil, cobrindo as interfaces de administração (desktop) e motorista (mobile).

Botões

Componentes

Variantes

Hierarquia de ações: Primary para ação principal, Secondary para alternativas, Ghost para ações sutis, Danger/Success para ações críticas.

Tamanhos

Três tamanhos para contextos diferentes: sm para tabelas/ações secundárias, padrão para UI geral, lg para CTAs destacados.
